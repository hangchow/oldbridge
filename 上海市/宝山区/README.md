## 说明

- 丰德桥：具体年代据老百晓集桥（名录原写“—”）。
- 万年桥：不在文保名录中，据老百晓集桥页面收录；已逐座核对页面，现存桥未见毁弃或1949年后重建的记载；年代按页面中本桥的记载，等级待核实。
- 来龙桥：具体年代据老百晓集桥（名录原写“—”）。
- 区级文物保护单位的时代，维基百科列表里没有写，暂标“—”。
- 乡镇一列按名录地址提取，个别只写到老街、地块的保留原文。
- 登记不可移动文物取自上海市文广影视局 2011 年公布的各区县名单（网页存档）；嘉定、崇明、虹口三区的名单存档无法获取，暂缺。
- 结构、长度标“—”的，是没有查到可靠资料。
