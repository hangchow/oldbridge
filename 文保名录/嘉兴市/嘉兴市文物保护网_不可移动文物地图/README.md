# 嘉兴市不可移动文物地图：离线归档与桥梁核对

来源：[嘉兴市文物保护网·不可移动文物地图](https://www.jxwwbh.cn/ConservationWeb/ConservationMap.aspx)。抓取日期：2026年11月5日。该站由嘉兴市文物保护与考古研究所主办。地图及详情未标统一资料修订日期，不能将抓取日期当作名单公布日期。

## 文件

- [完整原始接口、抓取状态和详情清单](manifest.json)：1226条基础记录，所有原始字段保留。
- [整理后的1226条记录](records.json)、[总目录CSV](catalog.csv)。区县、乡镇优先来自地区查询响应，再按目录树层级及明确地址前缀补充；推定字段与原始字段分开。
- [地图点位GeoJSON](points.geojson)：1217个可正常读取且位于嘉兴附近的点位；不包含4条空坐标及5条疑似X/Y颠倒记录。原始坐标仍完整保存在JSON和CSV。
- [桥梁核对JSON](bridge_review.json)、[桥梁核对CSV](bridge_review.csv)：344条桥梁候选，含既有记录快照、匹配依据、待核原因及采纳字段。
- [老百晓匹配与照片审核](cq_matches.json)：核对3个候选页面，2个采用，1个因桥型不符排除。采用的4张原图已复制到乡镇目录，候选页面与6张照片保存在 `cq/` 以便复核。
- `raw/`：地图页、目录树页、页面脚本、全部基础接口、7份地区查询响应及1226次详情响应。
- `details/`：1226个离线页面；其中676份有详情正文，其余550份明确标示仅有基础数据。
- `assets/`：详情中唯一提供有效src的图片（南湖中共一大会址，非桥梁），未误挂到桥梁条目。
- [文件SHA-256校验清单](SHA256SUMS.txt)。

## 抓取范围与限制

目录树1018个节点（55个行政层级、963个文物节点），与基础接口1226条的范围不同，均原样归档。可识别的分区包括南湖、秀洲、经开、港区、平湖、嘉善和海盐；本次地图中未见海宁、桐乡分区，不代表两地没有文物。

详情有550次返回脚本验证跳转或“非法访问”页面，没有取得正文；未绕过验证，也未把拦截页面当作文物简介。其他676份详情已归档。多数详情图片控件没有src，未下载站点页眉代作文物照片。

地图JavaScript以 `wkid:4326` 构建范围，本地保存接口原始X/Y，不独立保证其与其他底图完全一致，不作坐标转换。疑似颠倒的5条为高照粮站旧址、塘汇塘桥、荷花村正阳庙“奉宪禁示”石碑、《重修鲍塔村关帝庙乐善庵记》石碑、能仁寺石碑。

## 入库结果

344条桥梁候选按名称、乡镇、村址及原有记录核对：169条对应已有桥，169条新增，6条待核不计数。嘉兴530→699座；湖州及海宁数量不变。新增中的168条按地图“未核定文物保护单位”记为一般不可移动文物，另1条记为文物保护点（公布层级待核），不把“未核定”误算作文保单位或文保点。

已有桥只补缺失的地址、结构和长度；原有年代、等级及较完整地址保留。每条采用记录均附离线档案与原始坐标，地图归属与原分组不同的在备注并列说明。南石桥等已按用户确认采纳的新资料不被本地图覆盖。

石佛寺香花桥与兴善寺香花桥、洛西村万寿桥与来龙桥村万寿桥、西施浜青龙桥与西庄街青龙桥有明确村址差异，分别收录。老百晓jxql462照片为石梁桥，不符合洛西村万寿桥档案所述单孔石拱桥，排除该照片匹配。

## 可重复生成

`scripts/tools/download_jxwwbh_map.py` 归档公开接口和详情、保留缺项状态，支持缓存续传；`scripts/build/jxmap.py` 按已审核的 `bridge_review.json` 应用新增和补充，由 `jxprimary.py` 在城市生成及省级补全后调用。资料归档不等于确认所有桥梁的现行保护级别。
