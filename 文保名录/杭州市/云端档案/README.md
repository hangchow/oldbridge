# 项目常用云端档案

本目录仅缓存杭州桥梁明细直接引用的176份档案，以及网页所需的758张图片和共享样式。非桥梁及未使用的桥梁档案保存在完整镜像中。

完整镜像位于仓库同级的 `singdo_云端档案/`：

- `文保单位/`：wenbao 文保单位库。
- `历史建筑/`：libao 历史建筑库。

两库各有原始详情页、列表页、离线网页、资源、索引、资源清单和抓取报告；`项目缓存/`保存从本目录迁入的已处理档案，文件名保持不变。默认路径为 `/Users/sean/workspace/singdo_云端档案`，可通过 `SINGDO_MIRROR_ROOT` 设置其他位置。

维护命令见[脚本说明](../../../scripts/README.md)。
