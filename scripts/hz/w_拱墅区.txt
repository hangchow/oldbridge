'''拱墅区'''是[[中华人民共和国]][[浙江省]][[杭州市]]下辖的一个区，是杭州的中心城区之一。区内有小河直街、大兜路、桥西等历史街区，还有[[信义坊]]、胜利河等特色街区，以及[[半山国家森林公园]]等景区。

拱墅区历史悠久，[[隋]][[唐]]起就是[[杭嘉湖地区]]的货物集散地，因境内有[[拱宸桥]]、[[湖墅]]而得名。<ref>{{cite news|title=重磅消息！国务院批复同意杭州部分行政区划优化调整|url=https://hznews.hangzhou.com.cn/chengshi/content/2021-04/09/content_7943766_0.html|publisher=杭州网|date=2021-04-09|accessdate=2021-04-09|archive-date=2021-04-09|archive-url=https://web.archive.org/web/20210409064004/https://hznews.hangzhou.com.cn/chengshi/content/2021-04/09/content_7943766_0.html|dead-url=no}}</ref>区人民政府驻[[拱宸桥街道|拱宸桥街道台州路1号]]。

2021年2月22日，浙江省人民政府批复同意杭州市拱墅区人民政府驻地由湖墅街道珠儿潭巷10号迁移至拱宸桥街道台州路1号。2021年4月9日，原[[下城区]]和原拱墅区撤销，两区的行政区域合并成立新拱墅区，办公地址位于台州路不变<ref>{{cite web |author1=浙江省人民政府 |title=浙江省人民政府关于杭州市拱墅区人民政府驻地迁移的批复 |url=http://www.zj.gov.cn/art/2021/2/22/art_1229017138_2232668.html |website=浙江省人民政府 |access-date=2021-02-22 |archive-date=2021-06-03 |archive-url=https://web.archive.org/web/20210603122846/http://www.zj.gov.cn/art/2021/2/22/art_1229017138_2232668.html |dead-url=no }}</ref>。

== 地理位置 ==
拱墅区位于京杭大运河北南端，介于北纬 30°16′～30°24′，东经 120°04′～120°12′之间，为[[杭州市]]中心城区之一，曾为[[中国共产党杭州市委员会|杭州市委]]、[[杭州市人民政府|市政府]]所在地，境内拱宸桥和湖堤一字而得名。辖区面积 69.21 平方千米。其中，耕地 1.92 平方千米，林地 6.57 平方千米，村镇及矿用地 51.54 平方千米，水域及水利设施用地 3.36 平方千米，其他用地 5.82 平方千米。东邻江干区和下城区，西连西湖区，南接[[西湖区 (杭州市)|西湖区]]和[[下城区]]，北靠[[余杭区]]，东西最大距离 12.6 千米，南北最大距离 14.4 千米。<ref name=":0">{{Cite web |title=Wayback Machine |url=https://zjjcmspublic.oss-cn-hangzhou-zwynet-d01-a.internet.cloud.zj.gov.cn/jcms_files/jcms1/web2096/site/attach/0/55359ed334e542f4855d19c636ad00e9.pdf |website=zjjcmspublic.oss-cn-hangzhou-zwynet-d01-a.internet.cloud.zj.gov.cn |access-date=2025-02-05 |archive-date=2024-04-06 |archive-url=https://web.archive.org/web/20240406035428/http://zjjcmspublic.oss-cn-hangzhou-zwynet-d01-a.internet.cloud.zj.gov.cn/jcms_files/jcms1/web2096/site/attach/0/55359ed334e542f4855d19c636ad00e9.pdf |dead-url=no }}</ref>

== 自然环境 ==
辖区地势呈东北高西南低。东北部属[[天目山]]余脉，自西南向东北绵延10余千米，主要有[[半山]]、[[皋亭山|黄鹤山]]、[[青龙山]]、[[凉帽山]]、老虎山等。半山又名皋亭山，主峰海拔283.9米。青龙山，主峰海拔270米。凉帽山主峰海拔279米。老虎山主峰海拔256.4米。<ref name=":0" />

全区最高峰为黄鹤山，主峰海拔319.2米，西南部地势平坦，河道交错。<ref name=":0" />

==人口==
'''2022年初'''根据2021年5‰人口变动抽样调查，年末全区常住人口114.5万人，比上年增加2.3万人。全区户籍人口87.68万人，其中男性42.74万人，女性44.94万人，分别占总人口的48.7%和51.3%。全年出生人口0.67万人，人口出生率7.74‰；死亡人口0.63万人，死亡率7.30‰；人口自然增长率0.45‰。<ref>{{Cite web|title=2022年[杭州]拱墅区人口第七次人口普查有多少 警察-红黑人口库|url=https://www.hongheiku.com/xianjirank/zhejiangxj/4594.html|access-date=2023-04-08|website=www.hongheiku.com|archive-date=2021-06-12|archive-url=https://web.archive.org/web/20210612172050/https://www.hongheiku.com/xianjirank/zhejiangxj/4594.html|dead-url=no}}</ref>

2020年常驻人口112万。

年龄结构：

0-14岁：大约占 11.3%。

15-59岁：大约占 74.7%，是主要劳动年龄人口。

60岁及以上：大约占 14.0%，老龄化程度略有增加。<ref name=":0" />

全区有145541户，413949人户籍人口。（2020年）<ref name=":0" />

民族以[[汉族]]为主，有少数[[回族]]、[[满族]]、[[蒙古族]]、[[畲族]]、[[壮族]]、[[布依族]]、[[朝鲜族]]、[[侗族]]、[[瑶族]]、[[土家族]]等。
