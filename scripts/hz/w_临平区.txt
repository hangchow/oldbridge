'''临平区'''，是中华人民共和国[[浙江省]][[杭州市]]的一个[[市辖区 (中华人民共和国)|市辖区]]。在浙江省北部，杭州市东北部，北接[[湖州市]][[德清县]]、南连杭州市[[上城区]]、[[钱塘区]]，西隔[[京杭大运河|京杭运河]]与杭州市[[余杭区]]相望， 东邻[[海宁市]]， 是[[长江三角洲经济圈|长江三角洲都市群]]南翼的组成部分，杭州城的东北门户，區域总面積为286平方公里，區人民政府駐[[临平街道]]西大街33號。

2021年4月9日，杭州市调整行政区划，以原[[余杭区]][[运河]]为界拆分出东部的临平区、西部的新余杭区<ref name=":0">{{Cite web |title=在杭州区、县（市）里这位最年轻的兄弟势头正猛 |url=https://hznews.hangzhou.com.cn/chengshi/content/2023-03/23/content_8498075_0.htm |website=杭州网 |date=2023-03-23 |access-date=2025-01-05 |archive-date=2025-04-24 |archive-url=https://web.archive.org/web/20250424205936/https://hznews.hangzhou.com.cn/chengshi/content/2023-03/23/content_8498075_0.htm |url-status=live }}</ref>，下辖原余杭区的[[临平街道]]、[[东湖街道 (杭州市)|东湖街道]]、[[南苑街道 (杭州市)|南苑街道]]、[[星桥街道]]、[[运河街道 (杭州市)|运河街道]]、[[乔司街道]]、[[崇贤街道]]、[[塘栖镇]]。<ref name=":1">{{cite news |author1=浙江在线 |title=再次调整！杭州行政区划经历过哪些变化？ |url=https://zjnews.zjol.com.cn/zjnews/hznews/202104/t20210409_22363852.shtml |accessdate=2021-04-09 |archive-date=2021-04-10 |archive-url=https://web.archive.org/web/20210410182616/https://zjnews.zjol.com.cn/zjnews/hznews/202104/t20210409_22363852.shtml |dead-url=no }}</ref>

== 历史 ==

=== 民国以前 ===
临平之名，[[东汉]]时已见诸史册。临平得名于[[海迹湖]][[临平湖]]（又名鼎湖、东湖），《[[三國志|三国志]]》记载：“赤乌十二年（249）六月戊戌，宝鼎出临平湖。”唐宋时通舟楫，为著名旅游胜地。周围居民多从事盐业，故唐时有盐监之设。以后，随着自然条件变迁，临平湖逐渐淤塞，形成平原，宜种棉麻桑菜等作物。临平也逐渐由盐市演变为商业集镇。

[[唐朝|唐]]之前，属[[钱唐县]]。唐贞观四年（630）改属[[盐官县]]，置盐监。五代[[后梁]]龙德二年（922）属[[钱江县]]。[[北宋]]端拱元年（988）始建镇。天禧元年（1017）置都酒处，沽官酒。北宋太平兴国四年（979），钱江县更名[[仁和县]]。[[南宋]]绍兴十二年（1142），[[宋高宗]]赵构生母韦太后从金国南归，高宗亲自出行迎母，“车驾如临平，奉迎太后。”绍兴三十年（1160）置临平镇税监，兼烟火公事。[[明朝|明]]洪武十四年（1381）置税课局；后置临平铺司，设兵船，有事出海巡哨。<ref name=":3">{{Cite book |title=余杭县志 |author=余杭县志编纂委员会 |publisher=浙江人民出版社 |location=杭州 |year=1990 |isbn=7-213-00490-5}}</ref>

=== 杭县时期 ===
民国初废[[杭州府]]，置[[钱塘道]]。并[[钱塘县]]、[[仁和县]]两县为[[杭县]]。临平属杭县。

1953年12月，杭县县级机关由[[拱宸桥]]迁往临平后，临平逐步发展成为全县政治、经济、文化的中心。

1958年4月，杭县撤销，划为[[杭州市]]郊区。

1959年3月，杭州市郊区分成半山、拱墅两个联社；1960年1月，合并为[[钱塘联社]]（县级）。

=== 余杭时期 ===
1961年3月，原[[余杭县]]地域从[[临安县]]析出，并入钱塘联社（钱塘联社划出上泗公社全部、留下公社大部归杭州市）。4月，改县建制，定名余杭县。县城设临平镇，属杭州市。<ref name=":3" />

至1987年末，余杭县行政区划为1个县直属镇（区级）临平镇，临平区、塘栖区、三墩区、余杭区、瓶窑区5个区。临平区为[[县辖区 (中华人民共和国)|县辖区]]，辖4镇8乡，分别为双林乡、[[星桥乡]]、小林乡、乾元乡、翁梅乡、亭趾镇、五杭乡、博陆镇、[[九堡街道|九堡镇]]、大井乡、[[乔司街道|乔司镇]]、[[下沙街道|下沙乡]]，后来撤销。

1994年4月，撤销余杭县，设立[[余杭市]]。

2001年3月，撤销县级余杭市，设立杭州市余杭区，以原县级余杭市的行政区域为余杭区的行政区域。区人民政府驻临平镇。<ref>{{Cite web |title=浙江省人民政府关于撤销萧山市余杭市设立杭州市萧山区余杭区的通知 |url=https://www.hangzhou.gov.cn/art/2019/7/11/art_1662599_4873.html |website=www.hangzhou.gov.cn |access-date=2025-03-02}}</ref>

=== 临平区时期 ===
2021年4月9日，杭州市调整行政区划，以原[[余杭区]][[运河]]为界，拆分出东部的临平区<ref name=":0" />，临平区人民政府驻[[临平街道]]西大街33号，下辖原余杭区的临平街道、[[东湖街道 (杭州市)|东湖街道]]、[[南苑街道 (杭州市)|南苑街道]]、[[星桥街道]]、[[运河街道 (杭州市)|运河街道]]、[[乔司街道]]、[[崇贤街道]]、[[塘栖镇]]。<ref name=":1" />

== 历史文化 ==
临平区历史悠久，文化璀璨。2011 年考古发掘的临平山麓[[玉架山遗址]]清理出墓葬640余座、灰坑30余个，建筑遗迹11处，出土陶器、石器、玉器等各类文物8000余件（组），是良渚文化时期墓葬数量最多、出土文物最多的遗址。2012年4月13日，玉架山遗址被评为2011年度“[[全国十大考古新发现]]”之一。

临平地处杭城锁钥，历为[[京杭大运河|京杭运河]]交通要道。[[顾况]]、[[韦应物]]、[[刘长卿]]、[[苏轼]]、道潜、[[汪藻]]、[[杨万里]]、[[陸游|陆游]]、[[朱熹]]等皆于此留下足迹， 创作诗文， 也孕育了[[褚无量]]、[[曹仲达 (吴越)|曹仲达]]、[[丁養浩|丁养浩]]、[[沈楠]]、[[沈謙 (清朝)|沈谦]]、[[沈近思]]、[[孫士毅|孙士毅]]、[[俞樾]]、[[姚虞琴]]、[[孙晓村]]、[[何思敬]]等本地名人。

全区现有[[塘栖镇|塘栖]]1个省级历史文化名镇。有各级文物保护单位（点）42处。其中有[[大运河]]（含[[上塘河]]、[[广济桥 (杭州市)|广济桥]]、[[桂芳桥 (临平区)|桂芳桥]]）1处全国重点文物保护单位，另有[[吳昌碩|吴昌硕]]墓、海云洞摩崖题记、[[塘栖乾隆御碑与水利通判厅遗址]]、[[杭州海塘]]、[[乔司千人坑]]、[[玉架山遗址]]、[[长福桥 (杭州)|长福桥]]7处浙江省文物保护单位，栖溪讲舍碑、[[郭璞]]井、大纶丝厂旧址、清店桥、“超峰”题刻、隆兴桥、安平泉、临平山龙洞、余杭革命烈士纪念碑、中共鸭兰村支部旧址、独山碉楼、上环桥、雷家桥古纤道、淳安桥14处[[杭州市文物保护单位]]和塘栖水北明清一条街、塘栖八字桥檐廊一角、太史第弄、磻溪桥、花明村桥、白云桥、“虎岩”石刻、“洗心泉”“云岩奇泉”题刻、跌马桥、郭彬刘维申董代孝三烈士墓、三星桥、沾驾桥、万年桥、报恩新桥、永兴渡船桥、见龙桥、罗汉寺大殿旧址、洪家桥、九里塘凉亭、竹节关桥等20处[[杭州市文物保护点]]。其中，古建筑24处，近现代重要史迹及代表性建筑10处，石窟寺及石刻6处，古遗址1处，其他1处。

== 自然地理 ==

=== 地形地貌 ===
临平地势低平，孤丘散布。地处[[杭嘉湖平原]]南缘，背依[[天目山]]，前邻[[钱塘江]]，地势低平，零星出露[[皋亭山]]、[[超山]]、[[临平山]]、横山、丁山等孤丘。地势自南向北微倾，地貌分丘陵、平原2个类型。平均海拔5～7米。大部分区域覆盖古[[钱塘江]]、[[东苕溪]]和古[[杭州湾]]冲积形成的第四系海、湖、河相冲积层，局部出露有寒武系、志留系、泥盆系、石炭系、白垩系地层。最高点为南部的皋亭山，海拔361米，最低点在北部[[京杭大运河|京杭运河]]沿岸，海拔2〜3米。

=== 气候 ===
临平温和湿润，四季分明。全区属北[[亚热带]]南缘[[季风|季风气候]]区。温和湿润，四季分明，冬夏略长、春秋略短。春、夏、秋、冬四季平均分别为71 天、140 天、60 天、94天。夏季盛行东南风，炎热、湿润，冬季盛行西北风，寒冷，干燥。年平均气温为18.0℃。最热月为8月，平均气温29.5℃。最冷月为1月，平均气温5.9℃，月平均气温年较差23.6℃，极端最高气温为41.6℃（2024年8月3日），极端最低气温-8.0℃（2016年1月25日）。年均降水量1581.0毫米，降水最多年份降水1938.1 毫米（2018年）。主要气象灾害性有暴雨、台风、高温、雨雪冰冻、冰雹等，尤以暴雨灾害为甚，多发生在[[梅雨]]和台风期。

=== 水文 ===
临平水网纵横，湖沼密布。西、北濒[[京杭大运河|京杭运河]]，东、南邻[[钱塘江]]，区域内水网多为人工开凿或者经人工改造的河道，以京杭运河和[[上塘河]]为骨干呈网络状分布，河港交错，流量丰富，水位季节变化较大，兼有航运、灌溉、养殖、旅游等功能。主要河流有京杭运河、上塘河、杭州塘、沿山港、内排河、禾丰港、亭趾港等。钱塘江经人工开凿的和睦港沟通上塘河。河网密度为2.43千米/平方千米。京杭运河多年平均径流量为3.24亿立方米，上塘河为0.7亿立方米。[[元朝|元代]]以前，京杭运河主道经临平转东至[[海宁市|海宁]][[长安镇 (海宁市)|长安]]、 [[桐乡市|桐乡]][[崇福镇|崇福]]等地向北。元末，[[張士誠|张士诚]]开拓[[武林门]]至江涨桥段运河河道，京杭运河改经[[塘栖镇|塘栖]]向东。区内湖泊和沼泽湿地多为海迹湖，旧有[[临平湖]]等较大湖泊。 唐代以后，临平湖逐渐淤塞，现有湖沼主要集中在[[塘栖镇]]和[[运河街道 (杭州市)|运河街道]]，多面积小于0.5平方千米，荡漾相连，成片分布，主要湖泊、湿地有丁山湖、北塔漾、西太漾、洪人头漾、龙头漾、张泗漾、翁阿塘漾、芦荡漾、北大漾、黄家漾、九湖塘漾等。河湖汛期一般在4〜10月。其中，以6〜7月的梅汛为主，9〜10月的台风汛次之。

=== 土地资源 ===
2023年，根据第三次全国国土调查，临平区耕地面积4894.35公顷，园地面积2607.42公项，林地面积2165.21公顷，草地面积322.00公顷，湿地面积0.30公顷，均为内陆滩涂。城镇村及工矿用地12676.06公顷，交通运输用地1943.40公项，水域及水利设施用3926.51公项。

==人口==
据2024年全市5‰人口变动抽样调查推算，年末全区常住人口114.2万人，比上年末增加1.5万人。城镇化率89.5%。全区户籍人口65.26万人，年末总户数20.09万户，较上年末增加1.04万户。全年出生人口7428人，人口出生率11.6‰，人口自然增长率7.5‰，户籍出生婴儿性别比为110.01。<ref name=":2">{{Cite web |title=杭州市临平区2024年国民经济和社会发展统计公报 |url=https://www.linping.gov.cn/art/2025/4/27/art_1229524450_4348939.html#:~:text=根据全市统一初步核算，2024年全区生产总值（GDP）为1175.09亿元，按可比价计算，同比增长5.0%%E3%80%82,从GDP构成看，第一产业增加值18.19亿元，增长5.3%；第二产业增加值524.22亿元，增长3.9%；第三产业增加值632.68亿元，增长6.0%%E3%80%82%20全区三次产业增加值结构由上年的1.6:52.2:46.2调整为1.5:44.6:53.9，第三产业占比首次突破50%%E3%80%82 |website=杭州市临平区人民政府 |date=2025-04-27}}</ref>

===铁路===
清[[光绪]]三十二年（1906），经本区域的[[沪杭铁路]]动工。三十四年，杭州至[[海宁市|海宁]][[长安镇 (海宁市)|长安]]通车，[[宣統|宣统]]元年（1909）全线通车。现有沪杭、[[宣杭铁路|杭宣]]2条普通铁路，[[沪昆高速铁路|沪昆]]1条高速铁路，[[杭海城际|杭海]]1条城际铁路。由于2021年4月杭州市部分行政区划调整，自当年11月18日零时起，临平区[[南苑街道 (杭州市)|南苑街道]]的原余杭高铁站更名为[[临平南站]]，站内可换乘杭海城际。

== 经济 ==
2025年全区生产总值（GDP）为1216.31亿元，按可比价计算，同比增长5.1%。

从GDP构成看，第一产业增加值19.38亿元，增长5.7%；第二产业增加值533.20亿元，增长4.5%；第三产业增加值663.73亿元，增长5.5%。全区三次产业增加值结构由上年的1.5:44.6:53.9调整为1.6:43.8:54.6。按常住人口计算，人均地区生产总值为10.57万元（按年平均汇率折算1.48万美元）。

全区数字经济核心产业增加值91.15亿元，占GDP比重为7.5%。<ref>{{Cite web |title=杭州市临平区2025年国民经济和社会发展统计公报 |url=https://mp.weixin.qq.com/s/YOXhuaWWYLEMtvwJATq0PQ |access-date=2026-05-16 |archive-date=2026-05-18 |archive-url=https://web.archive.org/web/20260518070307/https://mp.weixin.qq.com/s/YOXhuaWWYLEMtvwJATq0PQ |url-status=live }}</ref>

临平有628家规模以上工业企业，其中199家亿元以上、20家10亿元以上，17家上市企业。特色优势产业有高端装备智造、生物医药、新材料。龙头企业有[[老板电器]]、[[春风动力]]、[[贝达药业]]等。<ref>{{Cite web |title=临平概况 |url=https://www.linping.gov.cn/art/2024/5/8/art_1229532075_31807.html |website=临平区人民政府 |date=2024-5-8}}</ref>
