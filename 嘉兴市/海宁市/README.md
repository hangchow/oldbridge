## 说明

- 宜家桥：具体年代据老百晓集桥（名录原写“清”）。
- 紫薇桥：具体年代据老百晓集桥（名录原写“元”）。
- 虹桥：具体年代据老百晓集桥（名录原写“清”）。
- 水脉堰桥：不在文保名录中，据老百晓集桥页面收录；已逐座核对页面，现存桥未见毁弃或1949年后重建的记载；年代按页面中本桥的记载，等级待核实。
- 平安桥：不在文保名录中，据老百晓集桥页面收录；已逐座核对页面，现存桥未见毁弃或1949年后重建的记载；年代按页面中本桥的记载，等级待核实。
- 乡镇一列照录名录原文；省保名录只写到区县的，乡镇标“—”。
- 同一座桥在多级名录中出现时，按最高等级记录一次。
- 结构、长度标“—”的，是没有查到可靠资料。
