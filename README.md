# oldbridge：江浙沪古桥文物名录

整理杭州、湖州、嘉兴、上海、苏州、金华、绍兴、宁波、衢州、台州、温州、丽水、舟山、无锡、南京、常州、镇江、扬州、泰州、南通、盐城、淮安、宿迁、徐州、连云港等地的古桥，收录各级文物保护名录和不可移动文物名录里的桥梁，内容包括结构、时代、位置、保护等级、公布文件和照片。浙江、上海和江苏全部十三个地级市（共二十五市）都已建立名录，统计表按浙江、上海、江苏的顺序排列；各市覆盖程度不同，见[数据覆盖情况](数据覆盖情况.md)。数据以政府公布的文保清单为基准，原件存放在 [文保名录/](文保名录/README.md)。

- **扬州市**：市保已用市政府原件（第一至四批 2008 年调整公布、第五批 2012 年）核对，但原件地址只写“市区”，廿四桥、大虹桥、迎恩桥这几座在维基广陵、邗江两个列表里重复出现，暂按廿四桥、大虹桥归邗江区、迎恩桥归广陵区列出；扬州市政府网站改版后，2022 年发布的《扬州市县级文物保护单位名录》链接已失效，高邮、宝应、仪征、江都的县保只有维基名单。
- **据博雅地名网（tcmap）汇编补录的桥**：徐州、江阴和这一轮的 26 座（泰州 7、南京江宁 4、连云港 2、宿迁 1、无锡 2、景宁 3、开化 2、温岭 1、桐乡 2、磐安 1、金东 1）找不到政府原件，等级说明里都注明了“据博雅地名网汇编，待核对政府原件”。
- **四普新发现（未定级不可移动文物）的覆盖仍不完整**：目前已收录杭州、绍兴、宁波、温州、丽水、上海、苏州的桥梁，数量见上方“各市按级别统计”。已找到的名单包括诸暨、柯桥、宁海、永嘉、缙云、吴中等区县，具体公告见“主要来源”和各区县文档；其他地区仍需继续查找公开名单，不能把尚未收录视为当地没有新发现古桥。
- **徐州市**：老百晓集桥徐州目录 134 页几乎都是现代桥，维基各区县列表只有白家桥、燕桥两座省保；徐州市政府网站查不到成批的市保名单，县保只在博雅地名网的汇编里找到沛县姚楼河普济桥。徐州古桥多毁于黄河泛滥，现存可能确实不多，但市保、县保和四普名单仍需政府原件核对。
- **苏北七市**：维基名单里的桥很少，收录的多是老百晓集桥逐页核对过的古桥（尚未定级）。大丰草堰庆丰桥据报道已列入第九批江苏省文物保护单位，但省政府网站的名单 PDF 是扫描件、读不出文字，暂按尚未定级列出，待核对原件。
- **乡镇未知**：部分国保、省保条目地址未写乡镇，标为“—”。

## 目录结构

25个城市统一采用“市/区县/乡镇（街道）”三级目录：

- `市/README.md`：全市统计、区县导航和排行。
- `市/区县/区县古桥.md`：桥梁总数、级别统计、乡镇导航和分类表格；说明及来源放在乡镇明细。
- `市/区县/乡镇/乡镇古桥.md`：逐桥列出结构、长度、时代、位置、文保等级、公布文件和图片，下附说明、资料来源及图片来源。
- 桥梁照片与乡镇明细放在同一目录，通常按 `桥名1.jpg`、`桥名2.jpg`、`桥名3.jpg` 命名，每桥最多三张；旧文件名保留迁移映射。
- 乡镇名称沿用资料记载；来源未明确乡镇的放入 `乡镇待核/`，不猜测归属。暂无桥梁记录的乡镇也保留空明细页。
- 图片归属不明时单独保存在 `图片待核/`，保留原图和来源，不挂到未经确认的同名桥。
- 跨区桥仍在相关区县分别列出，全市总数各计一次。
- `文保名录/` 保存原始公布文件、网页、表格、离线档案与检索记录。

例如：[拱墅区汇总](杭州市/拱墅区/拱墅区古桥.md)、[盐官镇明细](嘉兴市/海宁市/盐官镇/盐官镇古桥.md)。

## 收录范围

按保护等级从高到低：

1. 全国重点文物保护单位（含“大运河”“新叶村乡土建筑”“处州廊桥”等成组文物中单独列出的桥）
2. 省级文物保护单位（浙江省、江苏省文物保护单位）
3. 市级文物保护单位（浙江、江苏各地级市公布的，以及上海市文物保护单位）
4. 县（市、区）级文物保护单位（含上海各区公布的区级文物保护单位）
5. 文物保护点（浙江各市县的文物保护点、文物控制单位；上海各区的文物保护点）
6. 历史建筑（各市、县公布的历史建筑保护名录中的桥）
7. 一般不可移动文物（第三次全国文物普查登录）
8. 一般不可移动文物（照片确认）：未见于已公布的名录，但有文物部门所立“全国文物普查一般不可移动文物”标志牌的照片
9. 未定级不可移动文物（第四次全国文物普查新发现，已公示或公布的）
10. 尚未定级（已核实）：不在任何文保名录中，但桥现存、近年有实地照片，且年代或现状有纪年题刻或两个以上独立来源支持的古桥。“已核实”只说明桥确实存在、年代可靠，不代表有文保身份
11. 尚未定级（待核实）：“老百晓集桥”各市目录里收录、不在任何文保名录中的古桥（已逐座核对页面，删去现代桥、已毁、复建、移建、1949 年后重建的），以及少数据其他资料收录、等级待核实的桥。说明里都注明出处

各市实际收到哪几级、用了哪些名录，见[数据覆盖情况](数据覆盖情况.md)。

### 不收录

- **“尚未定级（待核实）”里 1949 年以后修建或重建的桥。** 这类桥只据“老百晓集桥”等资料收录，已逐座核对页面，删去现代桥、已毁、拆除、复建、移建、1949 年后重建的。
- 列入上面 1—9 类（文物保护单位、文物保护点、历史建筑、一般不可移动文物、四普新发现未定级不可移动文物）的桥，即使是 1949 年以后修建或重建的也照收，例如建德白沙大桥（1960，省保“新安江水电站”组成部分）、余姚祝江大桥（1966，省保）、温岭李婆桥（1968，省保）、“西湖三堤”市保中的杨公堤六桥（2003 年杨公堤恢复工程重建）、临安山田大桥（1965，历史建筑）、拱墅亦家桥（2013 年重建，一般不可移动文物）。
- 年代只写“现代”“近现代”“不详”的，在说明里标注“具体年代待核实”。
- 名称带“桥”字、实际不是桥的文物，比如“××桥遗址”“桥头××宗祠”“××桥烈士墓”“××桥抗战纪念碑”。

## 其他说明

- **桥名链接**：桥名只链接到本地保存的官方档案网页（杭州市文物遗产与历史建筑保护中心“云端档案”，存于 文保名录/杭州市/云端档案/），没有官方档案的桥名不加链接。桥名后的“?”链接到“老百晓集桥”网站上对应的桥（按区县、乡镇、桥名唯一匹配，匹配不到的不加“?”）。
- **结构**：结构一列括号里是孔数（拱桥即拱的数量）。部分结构信息来自“老百晓集桥”网站；杭州部分桥的结构、长度取自云端档案中保护范围图、历史建筑保护图则上的文字（图片文字识别），说明里注明“据云端档案保护图则”；标“—”的是没有查到可靠资料。
- **杭州市历史建筑**：来自云端档案的“历史建筑”库（singdo.org/libao/，各批历史建筑保护名单），桥梁记录的网页、照片和保护规划图则存于 文保名录/杭州市/云端档案/（文件名以“历保”开头），清单见 [云端档案_桥梁.md](文保名录/杭州市/云端档案_桥梁.md)。原按三普登录为一般不可移动文物、后列为历史建筑的桥，按历史建筑记录，说明里保留原等级。临安区第一批（杭政函〔2019〕54号）的名录和档案网页只有桥名，所在乡镇、年代、结构、长度据档案里的保护图则（图片文字识别）补齐；其中山田大桥为 1965 年钢筋混凝土拱桥，因已列为历史建筑而收录，不参加石木桥桥长排行。
- **2011 年余杭区三普名录**：名录里的“未定”指当时尚未定级。其中有些桥后来公布成了市级文保点，这些桥按较高的等级记录，不会重复列出。
- **文物保护点**：各市文保点都来自浙江省文物局《全省文物保护点》统计表，表里不区分市级、县级公布，统计时合为“文物保护点”一类（湖州、嘉兴各县的条目写作“××县文物保护点”，只是按所在县标注）。
- **迁建的桥**：从别处整体迁来的桥（如西湖杨公堤景区的玉涧桥、永福桥，2003年自桐庐迁建；毓秀桥，2003年自萧山迁建；新昌光霁桥、缙云漕头村同济桥、三墩章家桥），在“时代”一栏注明迁建，位置一栏写现址并注明原址，说明里写迁建经过。
- **新旧地名**：名录用的是旧乡镇名的（如临安区原藻溪镇、三口镇），已按现行区划归并，并在说明里注明。
