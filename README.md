# oldbridge：江浙沪古桥文物名录

整理杭州、湖州、嘉兴、上海、苏州、金华等地的古桥，收录各级文物保护名录和不可移动文物名录里的桥梁，内容包括结构、时代、位置、保护等级、公布文件和照片。按 杭州 → 湖州 → 嘉兴 → 上海 → 苏州 → 金华 的顺序整理，六市都已建立名录；各市覆盖程度不同，见下文“数据覆盖情况”。数据以政府公布的文保清单为基准，原件存放在 [文保名录/](文保名录/)。

## 目录结构

按“市/区县（/乡镇）”分目录。只有杭州市区分到乡镇（三级），其余都是最多两级（市/区县）：

- `杭州市/`：市辖区分到乡镇，县（市）不分乡镇，见下文。
- `湖州市/区县/`：如 `湖州市/安吉县/`。
- `嘉兴市/区县/`：如 `嘉兴市/桐乡市/`。
- `上海市/区/`：如 `上海市/青浦区/`。
- `苏州市/区县/`：如 `苏州市/吴中区/`。
- `金华市/区县/`：如 `金华市/武义县/`。
- `文保名录/`：各级政府公布的文保清单原件（网页、表格、文档），是本项目数据的基准。

杭州市的具体结构：

- **10 个市辖区**（上城、拱墅、西湖、滨江、萧山、余杭、临平、钱塘、富阳、临安）：`杭州市/区/乡镇或街道/乡镇或街道古桥.md`，例如 `杭州市/西湖区/三墩镇/三墩镇古桥.md`。这个乡镇的桥梁照片放在同一目录里。
- **3 个县（市）**（桐庐县、淳安县、建德市）不分乡镇：`杭州市/县/县古桥.md`，表格里有“乡镇”一列，照片放在县目录里。
- 照片按 `桥名1.jpg`、`桥名2.jpg`、`桥名3.jpg` 命名，每座桥最多 3 张。
- 名录里没有桥的乡镇也有一个文件，写明“未列入桥梁”。

## 收录范围

按保护等级从高到低：

1. 全国重点文物保护单位（含“大运河”“新叶村乡土建筑”等成组文物中单独提到的桥）
2. 浙江省文物保护单位
3. 杭州市文物保护单位；桐庐县、淳安县、建德市的县（市）级文物保护单位
4. 杭州市文物保护点
5. 杭州市历史建筑（只收录已核实的少数几座）
6. 一般不可移动文物（第三次全国文物普查登录）
7. 未定级不可移动文物（第四次全国文物普查新发现，2026 年公示或公布）

### 不收录

- **1949 年以后修建的桥。** 名录里年代写“中华人民共和国”或写明 1949 年以后年份的都不收，例如建德白沙大桥（1960）、拱墅花桥（1972）。
- 年代只写“现代”“近现代”“不详”的暂时保留，在说明里标注“具体年代待核实”。
- 名称带“桥”字、实际不是桥的文物，比如“××桥遗址”“桥头××宗祠”“××桥烈士墓”。

## 其他说明

- **西湖区三墩镇**：这一份是手工整理的，在官方名录之外，还补充了用户提供的未定级古桥，并核对了孔数、别名等信息。
- **结构**：结构一列括号里是孔数（拱桥即拱的数量）。部分结构信息来自“老百晓集桥”网站；标“—”的是没有查到可靠资料。
- **2011 年余杭区三普名录**：名录里的“未定”指当时尚未定级。其中有些桥后来公布成了市级文保点，这些桥按较高的等级记录，不会重复列出。
- **新旧地名**：名录用的是旧乡镇名的（如临安区原藻溪镇、三口镇），已按现行区划归并，并在说明里注明。
