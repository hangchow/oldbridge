# oldbridge：江浙沪古桥文物名录

整理杭州、湖州、嘉兴、上海、苏州、金华、绍兴、宁波、衢州、台州、温州、丽水、舟山、无锡、南京、常州、镇江、扬州、泰州、南通、盐城、淮安、宿迁、徐州、连云港等地的古桥，收录各级文物保护名录和不可移动文物名录里的桥梁，内容包括结构、时代、位置、保护等级、公布文件和照片。浙江、上海和江苏全部十三个地级市（共二十五市）都已建立名录，统计表按浙江、上海、江苏的顺序排列；各市覆盖程度不同，见下文“数据覆盖情况”。数据以政府公布的文保清单为基准，原件存放在 [文保名录/](文保名录/README.md)。

## 目录结构

按“市/区县（/乡镇）”分目录。只有杭州市区分到乡镇（三级），其余都是最多两级（市/区县）：

- `杭州市/`：市辖区分到乡镇，县（市）不分乡镇，见下文。
- `湖州市/区县/`：如 `湖州市/安吉县/`。
- `嘉兴市/区县/`：如 `嘉兴市/桐乡市/`。
- `上海市/区/`：如 `上海市/青浦区/`。
- `苏州市/区县/`：如 `苏州市/吴中区/`。
- `金华市/区县/`：如 `金华市/武义县/`。
- `绍兴市/`、`宁波市/`、`衢州市/`、`台州市/`、`温州市/`、`丽水市/`、`舟山市/`、`无锡市/`（含宜兴市、江阴市）、`南京市/`、`常州市/`、`镇江市/`、`扬州市/`、`泰州市/`、`南通市/`、`盐城市/`、`淮安市/`、`宿迁市/`、`徐州市/`、`连云港市/`：同样按“市/区县”分目录。
- 每个区县目录有一个汇总页 `区县名古桥.md`（如 `杭州市/拱墅区/拱墅区古桥.md`、`湖州市/德清县/德清县古桥.md`）：按级别统计、各乡镇数量、按级别列出，表格里有“图片”一列；除杭州市辖区外，后面还有说明、来源和图片来源，照片放在区县目录里。各市目录的 `README.md` 是全市汇总。
- `文保名录/`：各级政府公布的文保清单原件（网页、表格、文档），是本项目数据的基准。

杭州市的具体结构：

- **10 个市辖区**（上城、拱墅、西湖、滨江、萧山、余杭、临平、钱塘、富阳、临安）：`杭州市/区/乡镇或街道/乡镇或街道古桥.md`，例如 `杭州市/西湖区/三墩镇/三墩镇古桥.md`。这个乡镇的桥梁照片放在同一目录里。
- **3 个县（市）**（桐庐县、淳安县、建德市）不分乡镇：`杭州市/县/县古桥.md`（如 `杭州市/桐庐县/桐庐县古桥.md`），与其他城市的区县相同，照片放在县目录里。
- 照片按 `桥名1.jpg`、`桥名2.jpg`、`桥名3.jpg` 命名，每座桥最多 3 张。
- 名录里没有桥的乡镇也有一个文件，写明“未列入桥梁”。

1. 全国重点文物保护单位（含“大运河”“新叶村乡土建筑”“处州廊桥”等成组文物中单独列出的桥）
2. 省级文物保护单位（浙江省、江苏省文物保护单位）
3. 市级文物保护单位（浙江、江苏各地级市公布的，以及上海市文物保护单位）
4. 县（市、区）级文物保护单位（含上海各区公布的区级文物保护单位）
5. 文物保护点（浙江各市县的文物保护点、文物控制单位；上海各区的文物保护点）
6. 历史建筑（各市、县公布的历史建筑保护名录中的桥）
7. 一般不可移动文物（第三次全国文物普查登录）
8. 未定级不可移动文物（第四次全国文物普查新发现，已公示或公布的）
9. 尚未定级（待核实）：“老百晓集桥”各市目录里收录、不在任何文保名录中的古桥（已逐座核对页面，删去现代桥、已毁、复建、移建、1949 年后重建的），以及少数据其他资料收录、等级待核实的桥。说明里都注明出处

各市实际收到哪几级、用了哪些名录，见下面的“数据覆盖情况”。

### 不收录

- **“尚未定级（待核实）”里 1949 年以后修建或重建的桥。** 这类桥只据“老百晓集桥”等资料收录，已逐座核对页面，删去现代桥、已毁、拆除、复建、移建、1949 年后重建的。
- 列入上面 1—8 级（文物保护单位、文物保护点、历史建筑、一般不可移动文物、四普新发现未定级不可移动文物）的桥，即使是 1949 年以后修建或重建的也照收，例如建德白沙大桥（1960，省保“新安江水电站”组成部分）、余姚祝江大桥（1966，省保）、温岭李婆桥（1968，省保）、“西湖三堤”市保中的杨公堤六桥（2003 年杨公堤恢复工程重建）、临安山田大桥（1965，历史建筑）、拱墅亦家桥（2013 年重建，一般不可移动文物）。
- 年代只写“现代”“近现代”“不详”的，在说明里标注“具体年代待核实”。
- 名称带“桥”字、实际不是桥的文物，比如“××桥遗址”“桥头××宗祠”“××桥烈士墓”“××桥抗战纪念碑”。

## 其他说明

- **西湖区三墩镇**：这一份是手工整理的，在官方名录之外，还补充了用户提供的未定级古桥，并核对了孔数、别名等信息。
- **桥名链接**：桥名只链接到本地保存的官方档案网页（杭州市文物遗产与历史建筑保护中心“云端档案”，存于 文保名录/杭州市/云端档案/），没有官方档案的桥名不加链接。桥名后的“?”链接到“老百晓集桥”网站上对应的桥（按区县、乡镇、桥名唯一匹配，匹配不到的不加“?”）。
- **结构**：结构一列括号里是孔数（拱桥即拱的数量）。部分结构信息来自“老百晓集桥”网站；杭州部分桥的结构、长度取自云端档案中保护范围图、历史建筑保护图则上的文字（图片文字识别），说明里注明“据云端档案保护图则”；标“—”的是没有查到可靠资料。
- **杭州市历史建筑**：来自云端档案的“历史建筑”库（singdo.org/libao/，各批历史建筑保护名单），桥梁记录的网页、照片和保护规划图则存于 文保名录/杭州市/云端档案/（文件名以“历保”开头），清单见 [云端档案_桥梁.md](文保名录/杭州市/云端档案_桥梁.md)。原按三普登录为一般不可移动文物、后列为历史建筑的桥，按历史建筑记录，说明里保留原等级。临安区第一批（杭政函〔2019〕54号）的名录和档案网页只有桥名，所在乡镇、年代、结构、长度据档案里的保护图则（图片文字识别）补齐；其中山田大桥为 1965 年钢筋混凝土拱桥，不收。
- **2011 年余杭区三普名录**：名录里的“未定”指当时尚未定级。其中有些桥后来公布成了市级文保点，这些桥按较高的等级记录，不会重复列出。
- **文物保护点**：各市文保点都来自浙江省文物局《全省文物保护点》统计表，表里不区分市级、县级公布，统计时合为“文物保护点”一类（湖州、嘉兴各县的条目写作“××县文物保护点”，只是按所在县标注）。
- **迁建的桥**：从别处整体迁来的桥（如西湖杨公堤景区的玉涧桥、永福桥，2003年自桐庐迁建；毓秀桥，2003年自萧山迁建；新昌光霁桥、缙云漕头村同济桥、三墩章家桥），在“时代”一栏注明迁建，位置一栏写现址并注明原址，说明里写迁建经过。
- **新旧地名**：名录用的是旧乡镇名的（如临安区原藻溪镇、三口镇），已按现行区划归并，并在说明里注明。
