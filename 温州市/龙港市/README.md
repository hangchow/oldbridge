## 说明

- 贮壶桥：具体年代据老百晓集桥（名录原写“清”）。
- 徐家桥：具体年代据老百晓集桥（名录原写“民国”）。
- 鹤浦桥：具体年代据老百晓集桥（名录原写“清”）。
- 雁齿桥：不在文保名录中，据老百晓集桥页面收录；已逐座核对页面，现存桥未见毁弃或1949年后重建的记载；年代按页面中本桥的记载，等级待核实；具体年代据老百晓集桥（名录原写“南宋嘉熙年间”）。
- 年糕桥：不在文保名录中，据老百晓集桥页面收录；已逐座核对页面，现存桥未见毁弃或1949年后重建的记载；年代按页面中本桥的记载，等级待核实。
- 新兰社区陡门桥：不在文保名录中，据老百晓集桥页面收录；已逐座核对页面，现存桥未见毁弃或1949年后重建的记载；年代按页面中本桥的记载，等级待核实。
- 芦浦社区文明桥：不在文保名录中，据老百晓集桥页面收录；已逐座核对页面，现存桥未见毁弃或1949年后重建的记载；年代按页面中本桥的记载，等级待核实。
- 温州市文物保护点以浙江省文物局《全省文物保护点》统计表为准（原件存于本项目 文保名录/浙江省/）。
- 国保、省保、市保、县保依据维基百科整理，还没有核对政府原件；市保、县保名单可能不完整。
- 成组公布的文物（如古桥群）按单桥列出，组名写在文保等级里。
- 乡镇、结构、长度标“—”的，是没有查到可靠资料；部分结构、长度、年代来自“老百晓集桥”网站。
